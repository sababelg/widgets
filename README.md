# CurrencyStrip
Transparent 4x1 Android widget displaying USD/RUB and EUR/RUB from the Bank of Russia.

## Build
Import this folder into Android Studio and build APK, or push to GitHub and run the included GitHub Actions workflow. Download the `CurrencyStrip-debug-apk` artifact.

Add widget: long-press home screen > Widgets > Курсы валют. Tap either rate to refresh. Android may delay periodic updates; system widget updates are not guaranteed every 30 minutes.
